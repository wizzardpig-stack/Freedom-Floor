# Freedom Floor

An interactive systems exhibit exploring how economic pressure, access, labor, ownership, and everyday material conditions shape lived freedom.

## Live

GitHub Pages entry point:

`https://wizzardpig-stack.github.io/Freedom-Floor/`

## Current build

Canonical source:

`Freedom_Floor_V16_CINEMATIC_HUMAN_MACHINE_PASS(1).html`

The root `index.html` is intentionally a lightweight loader that forwards to the canonical versioned build. This avoids repeatedly renaming or rewriting a multi-megabyte single-file application.

## What it demonstrates

- interactive systems storytelling
- cinematic browser-based presentation
- custom data visualization and UI logic
- responsive single-file web application architecture
- iterative product direction, testing, debugging, and refinement

## Stack

HTML, CSS, JavaScript, browser-native APIs, Git/GitHub Pages.

## Development approach

Built through an AI-assisted development workflow with human product direction, visual design decisions, feature specification, testing, debugging, and iterative refinement.
